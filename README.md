# YourPower

A circuit builder + simulator game that teaches electrical engineering by playing: drag-and-drop components, real MNA simulation, and challenges like "make this node exactly 5V" mapped to a full Circuit Analysis curriculum.

**Status:** Planning complete (vision, research, architecture, UI/UX). Build not started.
